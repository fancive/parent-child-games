# 数字冒险

## 目标与用户

面向 3–6 岁孩子与陪伴的家长，通过帮小兔准备野餐认识数量、合并与拿走。
用户于 2026-09-28 选择：分层闯关，数数 → 10 以内加法 → 10 以内减法。

## 范围与产品决策

- 三个关卡：苹果林（数数）、胡萝卜田（加法）、野餐地（减法），每关 5 题。
- 按顺序解锁；已通过关卡可重玩。没有计时、生命值、扣分、广告或账号。
- 数数覆盖 1–10；加法的两个加数为正整数且和不超过 10；减法不出现负数，包含结果为 0 的题。
- 数数与加法每题数量逐步增加，避免同一轮反复出现同一答案。
- 每题 3 个不同的数字选项；答错留在原题，给点数提示，答对后由孩子点击继续。
- 可逐个点击物品点数；加法用两组物品，减法将送走的物品单独标出。
- 语音朗读是可选辅助，依赖设备中文语音；文字和图形始终可用。
- 保存已通关关卡及当前题目，刷新继续；存储不可用时仍可玩，并显示无法保存的提示。
- 本地服务作为验收入口。fancivez.com 已用于播客，不是本项目入口。

## 可观察验收

1. 从网站首页进入数字冒险，初始只开放苹果林，能看到三站地图。
2. 一题答错后不前进、不扣奖励，能点数后重新作答；答对后重复点击不重复计分。
3. 每关完成 5 题获得一枚野餐徽章并解锁下一关；通过三关出现野餐完成画面。
4. 刷新、返回地图、离开游戏再进入均能继续同一道题；重玩已过关卡不丢失解锁记录。
5. 减法出现例如 4 − 4 时，图形表达全部送走，正确答案为 0。
6. 手机 320px 宽及横屏无横向溢出，答题按钮至少 48px；支持键盘 Tab / Enter、明显焦点及减少动画偏好。
7. 首页入口、服务工作线程资源列表、Pages 打包包含本游戏；本地运行完整流程，无新增浏览器错误。

## 实现与验证计划

沿用纯静态 HTML/CSS/JS，无运行时依赖。`number-game/model.js` 负责确定性出题、判题、解锁及存档校验；`game.js` 负责 DOM、存储和可选语音；`styles.css` 用草地地图与物品托盘承载交互。

视觉：天空 #edf8ff、草地 #d9edb5、深叶绿 #254b3b、胡萝卜橙 #ed8b40、苹果红 #d34d50、纸白 #fffef7；圆润系统中文字体。地图为主要视觉，题目保持单一操作焦点，不堆叠面板。

增量：模型与边界测试 → 地图和答题闭环 → 入口/缓存/打包 → 浏览器通关与刷新/小屏验收。项目门禁为 `npm test`、`npm run lint`，新增文件使用 Prettier 检查。发布仍沿用现有流水线；本任务验证本地版本，不将推送等同线上验收。
