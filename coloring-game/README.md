# 涂色画板 · 小小画室

适合亲子一起玩的涂色画板：小花园、小猫咪、小火箭与自由画纸，12 种颜色，3 种笔尖。

- 点图案填色；自由画支持鼠标与触摸，橡皮擦可擦掉区域颜色或整笔线条。
- 每张画独立撤销/重做（最近 40 步），清空前确认，清空后也可撤销。
- 作品自动保存在当前浏览器；刷新后恢复图案颜色和线条，撤销历史不会跨刷新保留。
- “保存图片”导出 1440 × 1040 PNG；浏览器存储不可用或空间不足时会提示下载作品。
- 首次联网打开并缓存完成后可离线使用，不依赖外部字体或图片。

在仓库根目录运行 `python3 -m http.server 8099 --bind 127.0.0.1`，打开 http://127.0.0.1:8099/coloring-game/index.html 。

验证：`npm run lint`、`npm test`。浏览器验收使用环境已有的 Playwright：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node tests/coloring-game.e2e.cjs
```

可用 `COLORING_BASE_URL` 指定服务器；脚本覆盖首页入口、涂色、撤销/重做、图案独立存储、画笔、橡皮擦、清空取消/恢复、PNG 下载、离线重载、手机触摸及布局，并输出临时截图目录。
