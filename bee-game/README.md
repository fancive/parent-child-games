# 小蜜蜂，出发！

面向 5–6 岁孩子的纵向射击小游戏。采用绘本花园、圆润小蜜蜂与泡泡虫，所有图形由 Canvas 本地绘制，无外部图片、字体或音频请求。

- 拖动画面、按左右方向键，或按住屏幕上的方向按钮移动。
- 自动向上发射星星；击中一个泡泡虫得 10 分。
- 三关分别有 10、15、20 个目标，全部通过可获得 450 分。
- 粉色泡泡向下移动，碰撞消耗一颗爱心并提供 2.5 秒护盾。
- 三颗爱心用完后可重新开始；无倒计时。
- 暂停按钮、空格键和 Escape 可暂停。离开页面或窗口失焦时自动暂停。
- 音效可关闭；系统减少动态效果设置会关闭装饰性运动，保留必要的游戏运动。

从仓库根目录运行 `npm run serve`，打开 `/bee-game/index.html`；也可从游戏首页进入。

运行 `npm test` 和 `npm run lint`。`tests/bee-game.test.js` 验证碰撞计分、护盾、暂停、重开、三关通关和尺寸变化。

浏览器验收：开始 → 移动与命中 → 暂停恢复 → 三关通关 → 重玩；另检查窄屏触摸拖动、方向按钮按住与松开、窗口失焦、声音开关和玩法弹窗。
