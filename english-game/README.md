# 英语彩虹岛

配合 New MidiEnglish Thematic Workbook 3 和 Phonics Workbook 3 的原创词汇复习游戏。两本各 5 个单元、36 个词，默认全部可选；不用先知道课堂学到哪里。

- 主题乐园：听完整英文单词，在三张带中文标签的图里选择。英文默认隐藏，可以主动显示提示。答对后可听一句简单表达。
- 拼读工坊：听完整单词、看图，选择首字母，与给定词尾组成单词。只读完整词，不以 TTS 字母名称模拟音素。
- 每轮 6 题，需明确点“下一题”；错误可以继续尝试，无倒计时或扣分。单元词数少于 6、或错题不足 6 个时会重复练习。
- 自由选单元或混合复习。家长可将两本书各自的复习范围缩到前 N 单元，超出范围的题目和错题不会出现。收窄范围不删除已有记录。
- 错题先进入错题本；错题重练中一次答对会移除。本题先答错再重试，仍保留到后续练习。
- 完成一轮获得所练单元的贴纸；两本共 10 张，每单元一张，不重复计入收藏数量。完成轮数单独累计。
- 范围、家长读词模式、贴纸和错题通过 `localStorage` 保存在当前浏览器。刷新后开启新的一轮，未完成的题目不恢复；浏览器无法写入时会有可见说明。

英文发音由浏览器 `speechSynthesis` 提供，只有主动点击才会朗读。音色选择会排除 Albert 及已知的效果音、唱歌和耳语音色；其余英语音色先选系统默认，再优先选择 Samantha、Alex、Daniel 等常规朗读音色（美式英语优先），最后回退到其他英语音色。可用音色和实际音质仍取决于设备及浏览器。不支持、没有通过筛选的英语声音、朗读失败或请求超时时，页面说明情况并提供“显示单词”与家长读词模式。设备的静音/音量以及系统语音是否依赖网络无法由网页保证。未录音，未接入识别或评分。图片为本地 Emoji，无外部图片/字体依赖；不同系统的 Emoji 外观会不同。

## 本地验证

从仓库根目录运行：

```sh
node --test tests/english-game.test.js tests/english-speech.test.js
npx eslint english-game/*.js
npm run dev
```

打开 `/english-game/`。完整页面交互需在真实浏览器检验。此目录使用 ES modules，应通过 HTTP 服务访问。

## 内容来源与边界

按[官方 Level 3 大纲](https://midienglishpub.oss-cn-beijing.aliyuncs.com/NewMidiEnglish/resources/lessonPlan/Level3-LessonPlan.pdf)的主题与词族编排，实际页码和课堂顺序请以手中教材为准。本版以精选词汇复习为目标，未复刻课文、歌曲或练习页，也不代表整册知识点已覆盖。

拼读词族：

1. `ad / ag / ap / ab / at`
2. `am / an / ack / ed / eg`
3. `en / et / ell / it / ix / ick`
4. `ig / in / ill / og`
5. `ob / od / op / ot / ox / ock`

`data.js` 是词库；`model.js` 是可直接由 Node 测试的进度、出题、作答和奖励模型；`speech.js` 是可独立测试的英语音色选择逻辑；`game.js` 负责 DOM、语音播放与本地存储。添加词时应保证每题图片可辨，且拼读 `onset + rime === word`，三个积木选项包含且只包含一个正确首字母。
